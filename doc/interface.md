# SPLATTERDRIFT 界面与状态合同

## 信息层级

1. 主焦点：飞船、最近岩体、射击方向和可吸收制动涡旋。
2. 主操作：画布内单指按住/拖动；不显示常驻虚拟摇杆。
3. 持久信息：45 秒、完整度、场上岩体数、分数、CORE 等级和当前扇区。
4. 临时信息：首轮教学、CORE 升级、扇区切换、方向性飞溅、危险粒子与制动吸收。
5. 社交信息：平台内顶部冠军入口；结果状态的完整排行榜。
6. 次要操作：结果状态的“再次入轨 / RE-ENTER ORBIT”与“排行榜”。

## 屏幕与状态

| 状态 | 玩家问题 | 主焦点 | 操作 | 持久信息 | 恢复 |
|---|---|---|---|---|---|
| ready | 怎么动？ | 飞船、虚线方向、4 个岩体 | 第一次短点按或按住 | 45 秒 / 3 完整度 / 4 场上 / 0 分 / CORE ×1 | 首次有效射击进入 playing |
| playing | 该打谁、怎样控速？ | 最近岩体、弹丸、制动涡旋 | 单指射击/拖动/松手 | 时间、完整度、场上、分数 | 制动涡旋减速；碰撞后回中心 |
| sector-transition | 下一波有什么变化？ | 清场粒子环与扇区编号 | 650ms 内不射击 | 清场奖励、下一扇区 | 自动生成更密更快的一波 |
| failed | 为什么失败？ | “完整度归零”与指标 | 再次入轨 | 同上 | 一键重置 |
| time | 时间到了什么结果？ | “漂移结束”与指标 | 再次入轨 | 同上 | 一键重置 |
| leaderboard | 我与谁竞争？ | 名次、头像/名字和成绩 | 关闭；点他人打开资料 | 平台榜或外部下载入口 | 返回原状态 |
| paused-by-visibility | 无需额外理解 | 保留原画面 | 无 | 不推进时间、不继续连射 | 页面可见后从当前状态继续 |
| unsupported | 为什么不能玩？ | 明确错误文本 | 无 | 无 | 更换支持 Pointer Events 的浏览器 |

## 响应式与安全区

- `390×844`：逻辑场地以 `360×520` 显示；标题与 HUD 位于场地上方，整体垂直居中。
- `320×568`：场地约 `296×427.5`；隐藏 eyebrow 和教学第二行，不缩小关键数字。
- 场地内部输入坐标按实际边界映射回 `360×520`，权威物理不随 CSS 尺寸变化。
- 应用根层固定，触摸不抢键盘焦点；防止移动浏览器把画布滚动到视口顶部。
- platform-layout 不为 external guest banner 预留空间；外部访客栏只覆盖检查，不反向改构图。
- 390×844 与 320×568 的正式构图都以无访客栏状态验收；生产代码不包含为访客栏下移
  标题、HUD 或场地的 padding、margin、相机偏移。

## 控件状态

- 场地：默认 / focus-visible / pointer-captured / unsupported。
- 再次入轨：默认冷青细边和左侧能量标记、pressed 下移 `1px` 并反色、
  focus-visible 使用 `2px` 冷青外轮廓。
- 结果层出现后拦截场地输入；再次入轨与排行榜按钮并列且均不小于 44×44px。
- 排行榜是可滚动列表，行使用 `click` 而非 `pointerdown`；当前玩家行不可打开资料，
  其他玩家显示圆形头像+名字，缺头像时显示首字母。
- 顶部冠军入口只在真实 AlterU 会话出现；外部 `__alteru_guest__` 标记不会误判成平台身份。
- 所有模式都不依赖 hover；键盘方向与 Space 保留。

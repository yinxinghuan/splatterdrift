# SPLATTERDRIFT 界面与状态合同

## 信息层级

1. 主焦点：飞船、最近岩体、射击方向和可吸收制动涡旋。
2. 主操作：画布内单指按住/拖动；不显示常驻虚拟摇杆。
3. 持久信息：45 秒、完整度、场上岩体数、分数。
4. 临时信息：首轮教学、`×2–×4` 连击、方向性飞溅、危险粒子与制动吸收。
5. 次要操作：结果状态的“再漂一次”。

## 屏幕与状态

| 状态 | 玩家问题 | 主焦点 | 操作 | 持久信息 | 恢复 |
|---|---|---|---|---|---|
| ready | 怎么动？ | 飞船、虚线方向、6 个岩体 | 第一次短点按或按住 | 45 秒 / 3 完整度 / 6 场上 / 0 分 | 首次有效射击进入 playing |
| playing | 该打谁、怎样控速？ | 最近岩体、弹丸、制动涡旋 | 单指射击/拖动/松手 | 时间、完整度、场上、分数 | 制动涡旋减速；碰撞后回中心 |
| won | 我完成得怎样？ | 结果分数与清空结局 | 再漂一次 | 清除、命中、连击、制动、最高分 | 重置同一种子课程 |
| failed | 为什么失败？ | “完整度归零”与指标 | 再漂一次 | 同上 | 一键重置 |
| time | 时间到了什么结果？ | “漂移结束”与指标 | 再漂一次 | 同上 | 一键重置 |
| paused-by-visibility | 无需额外理解 | 保留原画面 | 无 | 不推进时间、不继续连射 | 页面可见后从当前状态继续 |
| unsupported | 为什么不能玩？ | 明确错误文本 | 无 | 无 | 更换支持 Pointer Events 的浏览器 |

## 响应式与安全区

- `390×844`：逻辑场地以 `360×520` 显示；标题与 HUD 位于场地上方，整体垂直居中。
- `320×568`：场地约 `296×427.5`；隐藏 eyebrow 和教学第二行，不缩小关键数字。
- 场地内部输入坐标按实际边界映射回 `360×520`，权威物理不随 CSS 尺寸变化。
- 应用根层固定，触摸不抢键盘焦点；防止移动浏览器把画布滚动到视口顶部。
- platform-layout 不为 external guest banner 预留空间；外部访客栏只覆盖检查，不反向改构图。

## 控件状态

- 场地：默认 / focus-visible / pointer-captured / unsupported。
- 重开：默认米白实底、pressed 下移 `1px`、focus-visible `2px` 外轮廓。
- 结果层出现后拦截场地输入；按钮使用 `click`，不与画布 `pointerdown` 双触发。
- 所有模式都不依赖 hover；键盘方向与 Space 保留。

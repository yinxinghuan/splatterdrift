# SPLATTERDRIFT / 溅迹漂移视觉方向

## 1. Visual thesis

- 游戏与受众：移动端 45 秒反冲 Asteroids，面向推荐流中的即时玩家。
- 情绪承诺：把失控惯性变成一张可以重新踩住的彩色航迹图。
- 视觉命题：一台米白喷射器在炭灰轨道印刷台上击碎墨阻岩体，并把命中沉淀为可回收制动花。
- 标志时刻：飞船高速擦过刚刚留下的彩色制动花，花瓣向内吸合，速度骤降后立刻反向开火。
- 必须品质：反冲方向可读、命中位置有记忆、制动花在混乱中仍可识别。
- 禁止方向：蓝紫霓虹太空、写实星空、玻璃 HUD、卡通火箭和无意义全屏粒子雨。

## 2. Composition and camera

- 固定正交 `360×520` 逻辑场地按视口缩放；DOM HUD 位于场地内部安全区。
- platform-layout 是主验收：顶部从 `env(safe-area-inset-top) + 14px` 开始，不为外部
  guest banner 永久下移；external-guest 只检查可用性。
- HUD 顶行占 58 逻辑像素，主体危险区从 `y=66` 开始；底部 `42` 逻辑像素保留首轮提示，
  提示消失后仍可进入游戏区域。
- 注意力路径：最近危险岩体 → 飞船朝向/虚线准星 → 弹丸 → 命中爆墨 → 制动花 → 下一条反冲路径。
- 无相机摇晃；碰撞使用主体闪烁与短环，不移动整张场地。

## 3. Color

- `press-black #17181C`：外部与场地背景，约 82%。
- `paper-white #F4F0E7`：飞船、岩体轮廓、主要数字，约 10%。
- `quiet-ink rgba(244,240,231,.52)`：网格、标签和教学。
- 动态墨色使用 `oklch(82% 0.19 hue)`，色相随命中推进，不做固定彩虹渐变。
- 危险提示使用 `#FF6B63`，只用于碰撞、低完整度和失败。
- 状态不能只靠颜色：大/小岩体尺寸不同，制动花有双环，危险有脉冲轮廓。

## 4. Typography

- 系统无衬线：`Inter, "Noto Sans SC", system-ui, sans-serif`。
- 标题 `18px / 900 / -0.04em`；HUD 数字 `18px / 850`；HUD 标签 `8px / 800 / .14em`；
  教学与结果正文不小于 `15px`。
- 标题固定英文 `SPLATTERDRIFT`；说明、状态和按钮走 zh/en i18n。
- 短屏隐藏非必要 eyebrow，不把关键数字缩到 12px 以下。

## 5. Shape, material, and lighting

- 飞船：白边圆环 + 一个明确的菱形枪口缺口，沿射击方向旋转。
- 岩体：6–8 边切角轮廓，内部用一条偏心短划表示旋转，禁止写实纹理。
- 弹丸：短椭圆；命中粒子：不规则圆点；制动花：双环 + 3 个偏心墨瓣。
- 材料只有平面墨、轮廓和少量同色 `box-shadow`；不使用玻璃、金属、体积光或通用 bloom。
- 网格极弱，只用于帮助读取速度和环绕，不竞争彩色残留。

## 6. Characters, environments, and assets

- 无人物、头像、照片、字体文件、3D 模型和音频文件。
- 游戏图形全部由 DOM/CSS 与自绘 SVG 路径构成。
- recoil-splatter-field 改编自 David Aerne 的 “CSS Splatters”；源码记录和 MIT 全文必须
  同时存在于 `upstream/SOURCE.md`、源码注释和 `public/THIRD_PARTY_NOTICES.txt`。
- `?baseline=1` 保留原始视觉机制的机械对照，不显示产品 HUD 与岩体。

## 7. UI and icons

- HUD 无卡片：左侧标题/时间，中部完整度，右侧场上数/分数；连击在飞船附近短暂出现。
- 结果层使用炭黑实底和一条动态墨色边线，不使用圆角弹窗。
- 唯一功能图标为重开箭头，使用自绘 `24×24` SVG、`1.7px` 圆端描边；按钮同时提供文字。
- 所有按钮目标至少 `44×44px`，pressed 用 `translateY(1px)` 与反色，focus-visible 用
  `2px` 米白轮廓。
- 禁止功能 Emoji。

## 8. Motion and VFX

- 输入：按下同帧更新虚线方向；65ms 武装前不产生弹丸。
- 射击：飞船 `90ms` 轴向压缩，弹丸同帧生成，反冲由权威速度体现。
- 命中：粒子在 `240–520ms` 内减速并沉淀；大岩体分裂在 `140ms` 内向两侧分开。
- 制动：双环在 `120ms` 内收束，残留点向飞船聚拢 `180ms`，飞船外圈显示一次收紧。
- 碰撞：飞船轮廓危险色闪烁 `180ms`，无敌期间每 `120ms` 交替显示。
- reduced-motion：关闭压缩、呼吸和聚拢位移；保留瞬时状态、权威运动和不透明度变化。

## 9. References translated into principles

- Asteroids：环绕、惯性、分裂、射击与生存；保留长期验证的风险结构。
- Recoil Asteroids 灰盒：移动只来自射击，反向短喷可刹车；保留已验证的触屏方向控制。
- CSS Splatters / recoil-splatter-field：弹丸爆裂后停驻比立即消失更有记忆；本作把停驻点
  升级成有限、可吸收的制动资源。
- 不复制 Asteroids 的像素美术、原作 UI 或音效；不照搬 Recoil Bloom 的六瓣边缘课程。

## 10. Anti-patterns

- 禁止让粒子、阴影或 CSS 外观参与岩体/弹丸碰撞。
- 禁止把制动花仅作为加分收藏品；吸收必须真实改变速度。
- 禁止自动回中、虚拟双摇杆、自动瞄准和点击目标瞬移。
- 禁止粒子无限累积、页面后台继续计时或恢复后补算。
- 禁止把结果做成分享海报或头像构图；本阶段先验证重复游玩。
- 禁止为了 external guest banner 下移平台内 HUD 或缩小主体。

## 11. Vertical-slice acceptance

- ready：首帧可见飞船、6 个大岩体、HUD 和一句“射击会把你推向反方向”。
- gameplay：单指短点按、长按、拖动、反向短喷均可完成；45 秒内有明确压力。
- high-feedback：命中生成可识别制动花，飞船穿过后速度至少下降 52%，并有同步视听反馈。
- result：胜利、完整度归零和时间结束均显示原因与关键指标，可一键重开。
- responsive：390×844 与 320×568 platform-layout 无溢出、HUD 不遮危险区、触控路径可达。
- baseline：`?baseline=1` 能运行原始边界飞溅/残留机制。
- performance：标准档活跃 DOM 对象不超过 180；窄屏/低动态档不超过 110；页面隐藏后无连射。

# SPLATTERDRIFT / 溅迹漂移需求文档

## 1. Overview

一款 45 秒竖屏 Asteroids 增强游戏：玩家只能靠连续射击的反冲移动，击碎漂移岩体，
并穿过命中后留下的粒子“制动涡旋”快速消除惯性。

### 产品与界面简报

- 玩家：AlterU 全屏推荐流中的移动端用户；无需登录、头像或前置选择。
- 场景：首屏 3 秒内可操作，单局 45 秒，失败或结算后可立即重开。
- 情绪承诺：每一枪同时是攻击和位移决定；玩家能把失控漂移重新变成有意图的轨迹。
- 主要动作：单指按住并拖动确定射击方向，松手停火，短点按发射一颗。
- 状态：ready、playing、won、failed、time、paused-by-visibility、unsupported。
- 目标尺寸：竖屏 `390×844` 与 `320×568`；桌面只做居中兼容。
- 输入：Pointer Events 单指主控，键盘方向键 + Space 作为可访问性与调试路径。
- 明确不做：头像玩法、好友选择、排行榜、生成图片、道具菜单和虚拟双摇杆。

## 2. Visual Design

- 世界是深石墨色的无重力测绘场；飞船、岩体和 HUD 使用暖白轮廓，所有能量粒子只使用
  冷青—近白的窄色域，危险使用少量珊瑚红。禁止彩虹色相轮换。
- 产品视觉使用单个 Canvas 2D：飞船移动持续留下衰减尾流，弹丸携带短路径，命中沿
  撞击方向喷出火花、碎屑和粉尘；产品模式不再为每个粒子创建 DOM 节点。
- 制动资源是低频粒子涡旋，不显示彩色圆环或花瓣。它必须与普通爆裂粒子区分：
  12–22 个粒子持续围绕权威中心流动；被吸收时整团向飞船收束。
- HUD 仅显示剩余秒数、完整度、场上目标、分数与当前连击；不使用卡片、玻璃面板、
  大面积 glow 或功能 Emoji。
- `?baseline=1` 保留 recoil-splatter-field 的原始指针射击、边界爆裂、后坐力和残留
  行为，用于机制回归；产品入口使用本游戏的岩体、计时与制动闭环。
- 精确视觉系统、响应式构图和反模式见 `doc/visual.md`。

## 3. Game Mechanics

### 局内参数

- 逻辑场地 `360×520`；固定步长 `1/120s`，渲染使用 `requestAnimationFrame`。
- 单局 `45s`，飞船完整度 `3`。
- 第 1 波生成 `4` 个大岩体；之后每波增加 1 个，最多 `7` 个。大岩体半径 `24`，
  命中后分裂为 `2` 个半径 `13` 的小岩体；小岩体再次命中后清除。
- 清空一波后进入 `650ms` 无射击换区窗口，获得 `250 × 当前波次` 分，然后生成下一波；
  清场不提前结束 45 秒局时。
- 第 1 波岩体初速 `28–54 px/s`，每波速度乘数增加 `14%`，最高 `1.56`；小岩体
  分裂基础速度 `76 px/s` 并应用相同波次乘数。飞船与岩体均屏幕环绕。
- 基础弹丸速度 `520 px/s`、寿命 `1.35s`、射击间隔 `110ms`。飞船每秒约 `18%`
  惯性阻尼，最大速度 `210 px/s`。
- 飞船与岩体相交扣 1 点完整度并获得 `1.15s` 无敌；完整度归零失败。

### 飞溅与制动涡旋

- 每次权威弹丸命中生成 `20–34` 个 Canvas 火花/粉尘/碎屑，并在命中点生成 1 个制动涡旋。
- 制动涡旋半径 `19`，存在 `8s`，最多同时存在 `12` 个；超过上限移除最旧项。
- 飞船中心距制动涡旋中心不超过 `29px` 时吸收它：飞船速度立即乘 `0.48`，
  得 `75 × 当前连击倍率` 分，并记录 1 次主动制动。
- 制动涡旋只影响飞船速度，不改变弹丸或岩体碰撞；粒子和 Canvas 外观不参与判定。
- 弹丸寿命结束只产生 `4–7` 个低亮粉尘，不生成制动涡旋，避免用空射刷制动资源。

### 计分与连击

- 大岩体命中/分裂得 `120` 分，小岩体清除得 `220` 分。
- 两次命中间隔不超过 `2s` 时连击倍率增加 1，最高 `×4`；超时、碰撞或空射累计
  `6` 发未命中时重置为 `×1`。
- 制动涡旋吸收延长当前连击窗口 `0.6s`，但不提高倍率。
- 连击倍率同时是局内 **CORE 等级**，直接改变武器和反冲，不增加新操作：
  - `CORE ×1`：单弹，`520 px/s`，弹丸半径 `3`，反冲 `42 px/s`。
  - `CORE ×2`：单弹，`550 px/s`，弹丸半径 `3.4`，反冲 `46 px/s`。
  - `CORE ×3`：聚焦弹，`585 px/s`，弹丸半径 `3.8`，可额外穿透 1 个岩体，
    反冲 `50 px/s`。
  - `CORE ×4`：同时发射夹角 `±3.7°` 的双弹，`625 px/s`，弹丸半径 `4.4`，
    不穿透，单次触发总反冲 `56 px/s`。
- 升级增加清场能力也放大漂移风险；碰撞、连击超时或连续空射会降回 `CORE ×1`。
  制动涡旋因延长连击并降低速度，成为维持高 CORE 的主要路线资源。
- 最终结果显示清除数、命中率、最高连击和主动制动次数；本地保存最高分。

### 视觉与性能分档

- 标准档：Canvas DPR 上限 `1.5`、活跃粒子池上限 `420`、最多 `12` 个制动涡流。
- 窄屏或 `prefers-reduced-motion`：DPR 上限 `1.15`、粒子池上限 `220`、最多
  `8` 个制动涡流；减少命中粒子和尾流采样，关闭闪光脉冲但保留方向、速度与状态变化。
- 页面隐藏时停止输入和 RAF 推进；恢复后不补算隐藏期间时间。

## 4. Controls

- 鼠标：`pointerdown` 朝指针立即发射并进入连射；移动改变绝对瞄准点；
  `pointerup / pointercancel` 停止。
- 触屏：按下同帧显示方向，`65ms` 后进入连射；武装前移动超过 `10` 逻辑像素立即
  连射；短点按在松手时发 1 颗。拖动持续改变单位方向，松手停止。
- 触屏准星固定在飞船前方 `92` 逻辑像素，不画在手指下方；飞船中心 `12` 逻辑像素
  死区沿用上一有效方向。一次只接受一个触点。
- 键盘：方向键每次旋转瞄准方向 `7.5°`，Space 按下射击、松开停止；焦点始终可见。
- 全画布使用 pointer capture 与 `touch-action:none`，并安装 iOS 长按防护。

## 5. Win / Lose Conditions

- 波次：清空当前岩体后继续生成更快的新一波，不设置提前胜利。
- 失败：飞船完整度降为 0。
- 时间结束：45 秒到时按当前分数、清除数与已完成波次结算。
- 结果层必须显示直接结局、总分、清除数、命中率、最高连击、主动制动次数、
  已完成波次、最高分和一个至少 `44×44px` 的“再次入轨”按钮。
- ready 首屏不设开始按钮；第一次有效射击启动计时和岩体运动。
- Pointer Events 不可用时显示明确不支持状态，不创建重复 touch/mouse 路径。

## 6. Sound Effects

- 首次用户手势后解锁 Web Audio；失败或不支持时静默降级。
- 射击：`150Hz → 64Hz`，方波，`65ms`，峰值增益 `0.018`，最短间隔 `76ms`。
- 大岩体命中：`210Hz → 330Hz` 三角波 `90ms` + `82Hz` 正弦低层 `70ms`。
- 小岩体清除：`360Hz → 620Hz` 三角波 `120ms`。
- CORE 升级：在命中声后叠加 `620 / 740 / 880Hz` 的 `70ms` 正弦短音；降级不另发声。
- 波次清空：`330 / 440 / 660Hz` 三音上行，每音间隔 `45ms`，不暂停输入反馈。
- 制动涡旋吸收：`520Hz → 310Hz` 正弦 `110ms`，同帧可选 `12ms` 轻震。
- 碰撞：`96Hz → 42Hz` 锯齿波 `160ms`；完整度归零追加 `52Hz` 低音 `280ms`。
- 获胜：`392 / 523 / 659 / 784Hz` 四音上行，每音间隔 `55ms`；时间结束使用
  `294 / 247Hz` 两音下降。
- `?mute=1`、系统静音或 AudioContext 失败时不影响玩法。

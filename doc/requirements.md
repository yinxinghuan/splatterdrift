# SPLATTERDRIFT / 溅迹漂移需求文档

## 1. Overview

一款 45 秒竖屏 Asteroids 增强游戏：玩家只能靠连续射击的反冲移动，击碎漂移岩体，
并穿过命中后留下的彩色“制动花”快速消除惯性。

### 产品与界面简报

- 玩家：AlterU 全屏推荐流中的移动端用户；无需登录、头像或前置选择。
- 场景：首屏 3 秒内可操作，单局 45 秒，失败或结算后可立即重开。
- 情绪承诺：每一枪同时是攻击和位移决定；玩家能把失控漂移重新变成有意图的轨迹。
- 主要动作：单指按住并拖动确定射击方向，松手停火，短点按发射一颗。
- 状态：ready、playing、won、failed、time、paused-by-visibility、unsupported。
- 目标尺寸：竖屏 `390×844` 与 `320×568`；桌面只做居中兼容。
- 输入：Pointer Events 单指主控，键盘方向键 + Space 作为可访问性与调试路径。
- 明确不做：头像玩法、好友选择、排行榜、生成图片、道具菜单和虚拟双摇杆。

## 2. Visual Design

- 世界是深炭灰的“轨道印刷台”；飞船、岩体和 HUD 使用米白轮廓，命中、飞溅、
  制动花使用连续色相的高彩墨色。
- 权威物体与视觉对象均使用 DOM/CSS 变换：飞船是白边圆形喷射器，弹丸是短椭圆，
  岩体是带切角的不规则墨阻轮廓，粒子从命中点爆裂并沉淀。
- 制动花必须与普通装饰粒子区分：它有外圈、中心点和缓慢收束的呼吸，且被吸收时
  产生朝飞船聚拢的短动效。状态不能只靠颜色。
- HUD 仅显示剩余秒数、完整度、场上目标、分数与当前连击；不使用卡片、玻璃面板、
  大面积 glow 或功能 Emoji。
- `?baseline=1` 保留 recoil-splatter-field 的原始指针射击、边界爆裂、后坐力和残留
  行为，用于机制回归；产品入口使用本游戏的岩体、计时与制动闭环。
- 精确视觉系统、响应式构图和反模式见 `doc/visual.md`。

## 3. Game Mechanics

### 局内参数

- 逻辑场地 `360×520`；固定步长 `1/120s`，渲染使用 `requestAnimationFrame`。
- 单局 `45s`，飞船完整度 `3`。
- 开局生成 `6` 个大岩体；大岩体半径 `24`，命中后分裂为 `2` 个半径 `13` 的小岩体；
  小岩体再次命中后清除。清空全部岩体立即获胜。
- 岩体初速 `28–54 px/s`，小岩体分裂速度 `76 px/s`；飞船与岩体均屏幕环绕。
- 弹丸速度 `520 px/s`，寿命 `1.35s`，射击间隔 `110ms`；每发向反方向施加
  `42 px/s` 冲量。飞船每秒约 `18%` 惯性阻尼，最大速度 `210 px/s`。
- 飞船与岩体相交扣 1 点完整度并获得 `1.15s` 无敌；完整度归零失败。

### 飞溅与制动花

- 每次权威弹丸命中生成 `8–14` 个短命粒子，并在命中点生成 1 个制动花。
- 制动花半径 `19`，存在 `8s`，最多同时存在 `12` 个；超过上限移除最旧项。
- 飞船中心距制动花中心不超过 `29px` 时吸收它：飞船速度立即乘 `0.48`，
  得 `75 × 当前连击倍率` 分，并记录 1 次主动制动。
- 制动花只影响飞船速度，不改变弹丸或岩体碰撞；粒子和 CSS 外观不参与判定。
- 弹丸寿命结束只产生 `3–5` 个短命墨点，不生成制动花，避免用空射刷制动资源。

### 计分与连击

- 大岩体命中/分裂得 `120` 分，小岩体清除得 `220` 分。
- 两次命中间隔不超过 `2s` 时连击倍率增加 1，最高 `×4`；超时、碰撞或空射累计
  `6` 发未命中时重置为 `×1`。
- 制动花吸收延长当前连击窗口 `0.6s`，但不提高倍率。
- 最终结果显示清除数、命中率、最高连击和主动制动次数；本地保存最高分。

### 视觉与性能分档

- 标准档：命中 `8–14` 粒子、最多 `12` 制动花、最多 `160` 个活跃/沉淀 DOM 墨点。
- 窄屏或 `prefers-reduced-motion`：命中 `5–8` 粒子、最多 `8` 制动花、最多
  `90` 个墨点；关闭飞船压缩和制动花呼吸，但保留权威运动与状态变化。
- 页面隐藏时停止输入和 RAF 推进；恢复后不补算隐藏期间时间。

## 4. Controls

- 鼠标：`pointerdown` 朝指针立即发射并进入连射；移动改变绝对瞄准点；
  `pointerup / pointercancel` 停止。
- 触屏：按下同帧显示方向，`65ms` 后进入连射；武装前移动超过 `10` 逻辑像素立即
  连射；短点按在松手时发 1 颗。拖动持续改变单位方向，松手停止。
- 触屏准星固定在飞船前方 `92` 逻辑像素，不画在手指下方；飞船中心 `12` 逻辑像素
  死区沿用上一有效方向。一次只接受一个触点。
- 键盘：方向键每次旋转瞄准方向 `7.5°`，Space 按下射击、松开停止；焦点始终可见。
- 全画布使用 pointer capture 与 `touch-action:none`，并安装 iOS 长按防护。

## 5. Win / Lose Conditions

- 胜利：45 秒内清空全部岩体。
- 失败：飞船完整度降为 0。
- 时间结束：仍有岩体时按当前分数结算，不伪装成胜利。
- 结果层必须显示直接结局、总分、清除数、命中率、最高连击、主动制动次数、
  最高分和一个至少 `44×44px` 的“再漂一次”按钮。
- ready 首屏不设开始按钮；第一次有效射击启动计时和岩体运动。
- Pointer Events 不可用时显示明确不支持状态，不创建重复 touch/mouse 路径。

## 6. Sound Effects

- 首次用户手势后解锁 Web Audio；失败或不支持时静默降级。
- 射击：`150Hz → 64Hz`，方波，`65ms`，峰值增益 `0.018`，最短间隔 `76ms`。
- 大岩体命中：`210Hz → 330Hz` 三角波 `90ms` + `82Hz` 正弦低层 `70ms`。
- 小岩体清除：`360Hz → 620Hz` 三角波 `120ms`。
- 制动花吸收：`520Hz → 310Hz` 正弦 `110ms`，同帧可选 `12ms` 轻震。
- 碰撞：`96Hz → 42Hz` 锯齿波 `160ms`；完整度归零追加 `52Hz` 低音 `280ms`。
- 获胜：`392 / 523 / 659 / 784Hz` 四音上行，每音间隔 `55ms`；时间结束使用
  `294 / 247Hz` 两音下降。
- `?mute=1`、系统静音或 AudioContext 失败时不影响玩法。
